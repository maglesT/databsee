# MEDHANTA brand kit (for video)

- **Logo:** medhanta-logo.png (900×544, for the end card and intro). Use it on a white or very light background.
- **Mark:** medhanta-mark.png (240×86, the small mark for a corner watermark).
- **Favicon:** favicon.png
- **Primary colour:** #e8500f (Medhanta orange). Darker hover: #c8410a. Soft tint: #fff1e8.
- **Gradient:** red → orange → amber: `linear-gradient(90deg, #dd1a10, #f4511e 55%, #f7941d)`. Use it for thin accent bars, title-card underlines and progress bars.
- **Grey:** #5f5f5f for secondary text; body text #2b2b2b on background #faf8f6.
- **Status colours in the app:** green #17803d (OK), red #c0352b (stop), amber #8a6100 (warning), blue #1f63b8 (info), purple #6b46c1 (assistant/AI suggestions).
- **Font:** Inter (fallback Segoe UI, system-ui).
- **Tone:** calm, clear, step-by-step tutorial. No hype, no invented numbers, no testimonials.
- **End card:** logo centred, product name, "Book a demo".
